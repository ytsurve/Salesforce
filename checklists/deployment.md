# Deployment Checklist

- [ ] Release artifact comes from the approved Git commit.
- [ ] Component list and dependencies match the approved plan.
- [ ] Validation succeeded and its result is recorded.
- [ ] Target org, API version, test level, and deployment window are reconfirmed.
- [ ] Pre-change metadata and reverse deployment artifact are available.
- [ ] Data backup/compensation and side-effect plan are ready where needed.
- [ ] Go/no-go approval is recorded.
- [ ] Immediate verification and monitoring actions are ready.
- [ ] Deployment ID, result, and post-deployment checks are recorded.
