# Pre-Change Checklist

- [ ] Requested outcome and affected users are confirmed.
- [ ] Relevant repository and org evidence is recorded.
- [ ] Target org, alias, and environment type are confirmed.
- [ ] Affected metadata, data, permissions, automation, integrations, and jobs are identified.
- [ ] Smallest safe solution and alternatives are documented.
- [ ] Test cases and success criteria are defined.
- [ ] Pre-change baseline and rollback artifact exist.
- [ ] Explicit approval has been received.
