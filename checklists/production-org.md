# Production Org Checklist

- [ ] Target is explicitly identified as the intended production org.
- [ ] No credentials, customer data, or unredacted logs will be stored or displayed.
- [ ] Requested action is scoped and approved.
- [ ] Current metadata was compared with the approved source where relevant.
- [ ] Side effects for Flow, Apex, email, integrations, data, and scheduled work are assessed.
- [ ] Rollback decision owner, executor, and communication owner are known.
- [ ] Monitoring window and success criteria are defined.
