# Testing Checklist

- [ ] Happy-path behavior succeeds for the affected user type.
- [ ] Failure and boundary conditions behave safely.
- [ ] Required permissions, CRUD/FLS, sharing, and user context are checked.
- [ ] Bulk, recursion, limits, asynchronous, and integration behavior are considered where relevant.
- [ ] Existing automation and regression paths are checked.
- [ ] Rollback verification is defined for production work.
- [ ] Results are recorded with evidence, not asserted from expectation.
