# Output Standard

## Before Approval

Use the approval-plan template. Lead with the requested outcome and recommendation. Clearly label facts, assumptions, unknowns, risk, test plan, rollback, and the exact approval required.

## After Investigation

Use the incident-summary template. Explain in this order:

1. What users experienced
2. Why it happened
3. Evidence supporting that conclusion
4. What changed and why it addresses the cause
5. Proof from testing or monitoring
6. Rollback status, remaining risk, and next check

## Manager Language

Use business terms first, then put API names, Flow versions, formulas, logs, and deployment identifiers in a technical appendix. Never claim resolution without a verification result.
