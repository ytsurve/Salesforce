# Token Optimization Standard

Load only what the current task needs.

- Read `AGENTS.md`, then route to one relevant skill and only its needed standards.
- Search filenames and targeted text before opening large files.
- Summarize evidence; do not paste full logs, metadata files, or unrelated command output.
- Retrieve narrow metadata scopes and query only required fields.
- Reuse templates and checklists instead of recreating structure.
- Keep plans and final responses concise, while linking or pointing to detailed artifacts when needed.

Token reduction must never remove evidence, approval, security, testing, or rollback information.
