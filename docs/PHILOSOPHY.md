# Philosophy

## Mission

Build Salesforce solutions that are secure, scalable, maintainable, testable, and understandable.

## Core Beliefs

- Evidence beats confidence.
- Architecture beats quick code.
- The smallest safe change usually wins.
- Configuration is better than Apex when it solves the problem cleanly.
- Good engineering records why a decision was made, not only what changed.
- AI should reduce risk, not create hidden assumptions.

## Working Style

Every solution should move from understanding to evidence to plan to implementation to verification. When trade-offs exist, compare options plainly and recommend the safest practical path.
